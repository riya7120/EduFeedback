# EduFeedback

EduFeedback – Faculty Feedback and Course Evaluation Portal

About the Project

EduFeedback is a web-based Faculty Feedback and Course Evaluation Portal designed to make the process of collecting student feedback simple, organized, and efficient.
The website allows students to explore courses, provide feedback about faculty members, and submit course evaluations through a user-friendly interface.

Technologies Used

HTML5 – Structure of the website

CSS3 – Styling and layout

JavaScript – Basic interactivity and functionality
